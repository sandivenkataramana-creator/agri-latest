⚠️ COMMON ISSUE: "Duplicate Email" Error

If you get: "Email address is already in use by another HOD..."
This means the email you entered ALREADY EXISTS in the system.

Currently in use emails:
  1. ramanaiahsandi@gmail.com
  2. svramana1998@gmail.com
  3. test@example.com
  4. Yasmeenbasha@gmail.com

✅ SOLUTION:

Option 1: Use a UNIQUE email (not in the list above)
  Examples:
  - newhod@yourdomain.com
  - john.doe@example.com
  - principal123@school.edu
  - ANY email not listed above

Option 2: Leave email BLANK (empty)
  - Just skip the email field or clear it
  - This is fine - the system allows NULL emails

Option 3: Use timestamp-based email (for testing)
  - newhod@yourdomain.com (gets unique ID each time)

🔧 HOW TO CREATE A HOD:

1. Click "Add New HOD" button
2. Fill in:
   ✓ Name (required)
   ✓ Department (required)
   ✓ Category (optional)
   ✓ Email (optional - MUST BE UNIQUE if provided)
   ✓ Phone (optional)
   ✓ Status (optional, default: active)

3. Click "Create"
4. If successful → Click "Send Password"
5. Auto-generated password sent to HOD's email

📝 EXAMPLE:
  Name: Dr. New HOD
  Department: Finance
  Email: dr.new.hod@example.com
  Phone: 9876543210
  Status: active

✅ Click Create
✅ System creates account
✅ Click Send Password
✅ Password emailed to dr.new.hod@example.com

If you get an error, make sure:
  ✓ Email is UNIQUE (not used by any other HOD)
  ✓ OR email field is BLANK
  ✓ Name is not empty
  ✓ Department is not empty
